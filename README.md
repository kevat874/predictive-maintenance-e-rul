# Predictive Maintenance – Remaining Useful Life (RUL)

End-to-end project for **Remaining Useful Life estimation** on the NASA **C-MAPSS** turbofan engine degradation dataset.

> **Important:** C-MAPSS is **SIMULATED** data generated by NASA’s Commercial Modular Aero-Propulsion System Simulation. Results do not transfer directly to real engines without domain validation.

## Problem

Given multivariate sensor time series from a fleet of turbofan engines, predict how many operational cycles remain before failure (RUL). The test trajectories end some time before failure; the goal is to predict the remaining cycles.

## Dataset

Four subsets with increasing difficulty:

| Subset | Train engines | Test engines | Operating conditions | Fault modes |
|--------|---------------|--------------|----------------------|-------------|
| FD001  | 100           | 100          | 1                    | 1 (HPC)     |
| FD002  | 260           | 259          | 6                    | 1 (HPC)     |
| FD003  | 100           | 100          | 1                    | 2 (HPC+Fan) |
| FD004  | 249           | 248          | 6                    | 2 (HPC+Fan) |

Raw files live in `data/raw/` (`train_FD00X.txt`, `test_FD00X.txt`, `RUL_FD00X.txt`).

## Setup

```bash
cd predictive-maintenance-rul
python3 -m venv .venv   # if supported
source .venv/bin/activate  # or use system Python
pip install -r requirements.txt
```

Data is already present under `data/raw/` if you used the automated download. Otherwise place the C-MAPSS text files there.

## Pipeline highlights

1. **RUL labels:** `max_cycle - cycle`, capped at 125 (piecewise linear).
2. **Constant sensors** dropped using train variance only.
3. **Normalization:** MinMax on train for FD001/FD003; KMeans (k=6) on operating settings + per-cluster MinMax for FD002/FD004. **Never fit on test.**
4. **Validation:** engine-level splits (GroupKFold / held-out engines), never row-wise.
5. **Evaluation:** RMSE and NASA asymmetric score on the **last cycle** of each test engine.
6. **Novelty:** failure-risk classifier, Isolation-Forest health index, SHAP, MC-Dropout uncertainty, cost-based decision layer.

## Cost model (decision layer)

- Unplanned failure cost = 100  
- Early maintenance cost = 10  
- Inspection cost = 2  

Rules: RUL > 60 → OK; 30 < RUL ≤ 60 → Schedule Inspection; RUL ≤ 30 → Urgent.

## Limitations

- Simulated data only; sensor noise and degradation models are synthetic.
- Operating-condition clustering is a heuristic; real multi-condition regimes may need more careful domain knowledge.
- Deep models are modest (CPU-friendly); larger architectures / longer training can improve RMSE.
- NASA score is highly sensitive to late predictions; small changes in a few engines dominate the total.
